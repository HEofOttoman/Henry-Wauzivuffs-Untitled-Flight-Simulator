# Henry Wauzivuff's Untitled Flight Simulator Project
![Main Menu Banner](<aesthetic-flight-simulator/Images/Backgrounds/Artwork/Main Menu Background.png>)

A flight simulator made by Henry Wauzivuff with Godot.
made in Godot by Henry Wauzivuff as a small and simple side project. 

The game features the Douglas A-26 Invader bomber aircraft, and currently has the following game worlds:
1. A small Tutorial Map
2. A small map based on Dove Lake, Tasmania
3. A large map covering the entirety of Tasmania
